
# Real-Time Financial Fraud Detection Pipeline

## Project Overview
This project develops a real-time financial
transaction fraud detection system using
Machine Learning and Big Data technologies.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- Apache Kafka
- Apache Spark
- MongoDB
- Grafana
- Prometheus

## Main Objectives
1. Analyse financial transactions.
2. Detect suspicious transactions.
3. Generate real-time fraud alerts.
4. Store transaction information.
5. Visualize fraud detection results.
